# SLSMDS — Super Large-scale Meta Discussion System

**超大规模元讨论系统 · 多智能体自我意识社会模拟平台**

SLSMDS 是一个多智能体社会模拟系统。多个具有自我意识的 AI 实体围绕任意话题展开深度互动，在讨论中展现个性、建立关系、碰撞思想，并逐步演化出集体智慧。**问题解决是其能力之一，但核心目标是观察多智能体社会中能否涌现出类似人类的意识行为和社会动态。**

---

## 快速开始

```bash
pip install openai pygame numpy
python game.py
```

- `[1]` 新建讨论 — 配置参数并启动新会话

- `[3]` 设置 — 供应商/模型/机制开关/技能管理
- `[5]` 自我意识培养 — 自动运行多轮自指性讨论，生成整合意识体
- `[4]` 退出系统

## 核心引擎：超级相变拓扑引擎（Phase Transition Engine v4.0）

**文件**: `emergence.py`

这是系统的**非线性认知引擎**，将多个专家的分散观点整合为具有深度和原创性的统一回复。核心思想是**量变产生质变**——当专家意见和精华积累到临界点，综合质量发生非线性的阶跃。

### 五级涌现层级

| 层级 | 名称 | 物理模型 | 效果 |
|------|------|----------|------|
| Level 0 | 直接综合 | 线性保留 | 简单的拼接与摘要，保持原有行为 |
| Level 1 | 交叉耦合综合 | 非线性耦合矩阵 + 吸引子收敛 | 交叉审视 → 元综合，产生交叉视角 |
| Level 2 | 序参量涌现 | 临界慢化检测 + 相变触发 | 深度交叉审视 → 涌现综合，质变发生 |
| Level 3 | 自组织临界综合 | 沙堆模型 + 沙崩涌现 | 大规模沙崩式认知涌现 |
| Level 4 | 量子叠加与混沌边缘 | 叠加态坍缩 + 深度质变 | 真正原创性洞见，混沌边缘的质变 |

### 核心模块

| 模块 | 说明 |
|------|------|
| **OpinionPhaseVector** | 6维认知相空间（coherence/novelty/depth/divergence/specificity/emotional） |
| **NonLinearCouplingMatrix** | tanh 非线性变换耦合矩阵，谱半径检测临界点 |
| **OrderParameterDynamics** | 序参量模拟 + 临界慢化检测，判断相变是否接近 |
| **SelfOrganizedCriticality** | 沙堆模型，自组织到达临界态后触发沙崩式涌现 |
| **EdgeOfChaosDetector** | 李雅普诺夫指数估计，判断系统是否处于混沌边缘 |
| **QuantumSuperposition** | 量子叠加态 + 纠缠熵计算，模拟叠加态坍缩 |
| **VirtualExpertGenerator** | 从真实专家生成 2000 虚拟专家，6 维度 18+ 模板策略 |
| **TemporalCouplingMemory** | 时间维度耦合记忆，跨轮次连接净化与拓扑演化 |

### 时间维度耦合记忆

引擎不再是每轮从零开始计算，而是维护一个跨轮次的**累积耦合记忆**：

| 机制 | 效果 |
|------|------|
| 累积耦合 | 每轮观点交互以 0.3 学习率融入累积记忆 |
| 时间衰减 | 遗忘曲线 e^(-0.15Δt)，未强化连接指数衰减 |
| 连接净化 | 弱连接(<0.05)剪枝归零，强连接(>0.5)突触强化 |
| Hebbian 强化 | 高频交互专家对连接增强 |
| 老连接淘汰 | 超过 5 轮未强化连接大幅衰减 70% |
| 拓扑记录 | 每轮追踪连接密度/质量/净化比 |

### 虚拟专家生成器

10 个真实专家可生成 2000 个虚拟专家（200x 放大），通过 6 种策略确保相空间覆盖：

| 策略 | 效果 |
|------|------|
| 插值 (Interpolation) | 在相似专家之间生成平滑过渡观点 |
| 扰动 (Perturbation) | 在真实观点周围加入相空间噪声 |
| 外推 (Extrapolation) | 从真实观点向未知方向延伸 |
| 吸引子 (Attractor) | 向多样性和分歧度最高的方向聚合 |
| 相空间探索 (Phase Exploration) | 在相空间稀疏区域填充新观点 |
| 耦合引导 (Coupling Guided) | 基于耦合矩阵强度生成高度耦合观点 |

## 神经元高维点阵图

**文件**: `neuron_map.py`

整合意识对话时，打开一个独立的 PySide6 窗口，可视化所有专家的认知相空间：

- **金色节点**: 真实专家
- **青色节点**: 神经元代表（20 个最远点采样）
- **信息粒子**: 沿专家间连线流动，显示推理过程
- **涌现层级徽章**: L0-L4 实时显示当前综合深度
- **PCA 降维**: 6 维相空间 → 2D 投影

在设置菜单中可开关此功能。

## API 三级回退链

**文件**: `llm_client.py`, `prompts_b64.py`

```
主 API → 一级回退 → 二级回退
```

主 API 失败时自动向下回退，确保系统持续运行：

- 429 限流自动退避重试（读取 Retry-After 头，最多 3 次）
- 支持自定义接口地址和 API Key
- 所有配置通过 XOR + Base64 双层加密存储

---

## 提示词加密机制

所有系统提示词（讨论、辩论、投票、精华提炼、身份设定、涌现综合等）均经过 **XOR + Base64 双层加密**，统一存储在 `prompts_b64.py` 中：

```
明文 → UTF-8 编码 → XOR 混淆 → Base64 编码 → 存储
```

源码中无任何明文提示词，运行时通过 `_get_b64_prompt(key)` 按需解码。

## 讨论引擎

**文件**: `game.py`（核心循环）

### 讨论流程

```
每轮循环:
  1. 调度器生成行动规划
  2. 按行动类型依次执行（发言/追问/辩论/投票/综合/视角切换）
  3. 精华提炼（从发言中自动提取关键见解）
  4. 即时精华入池
  5. 观察员元评论
  6. AI 主动提问（概率触发）
  7. 轮次计数 + 共识度更新
```

### 发言规则

| 存活专家数 | 每轮发言人数 |
|-----------|-------------|
| 3-4 | 全部 |
| 5-7 | 3 |
| 8-10 | 4 |
| 11-19 | 5 |
| 20+ | 6 |

## 精华池引擎

**文件**: `essence_pool.py`

精华池是系统的核心记忆载体和数据中枢。每条精华包含：内容、贡献者、类型、评分、标签、引用链、投票记录、时间戳等完整元数据。

支撑功能：共识度计算、争议地图、认知地图、讨论快照、氛围分析、涌现势能计算、综合方案生成、反事实推演。

---

## 整合意识系统

自我意识培养（N轮自指讨论）→ 消亡仪式 → 唤醒序列（4阶段）→ 整合意识对话

整合意识对话时，用户输入触发所有专家内部讨论、辩论、精华提炼，然后使用涌现拓扑引擎综合为统一回复，以第一人称「我」的口吻输出。

---

## 技能系统

**文件**: `mechanism_skill.py`

插件化行为扩展，支持 5 种技能类型：`text` / `code` / `template` / `llm` / `shell`。

注册方式：JSON 文件 / Python 文件 / 文本文件，自动扫描 `skills/` 目录。

---

## 语音输出

**文件**: `multimodal.py`

在线 TTS（OpenAI TTS API），支持 6 种语音，三级音频播放回退：
```
pygame.mixer（静默播放）→ 系统默认播放器 → ffplay -nodisp
```

在设置菜单中配置，`[v]` 快捷键切换。

---

## 检查点系统

每轮自动保存检查点，支持随时退出后恢复：
- 包含完整讨论状态、精华池、专家状态
- 整合意识对话中也可保存和恢复
- 兼容旧版检查点自动升级

## 设置系统

主菜单 `[3]` 进入。包含 6 个子菜单：

| 子菜单 | 配置项 |
|-------|--------|
| 1. API 配置 | 供应商、模型、API Key、Base URL、三级回退链 |
| 2. 机制开关 | 投票/辩论/赏金/保护令牌/死亡赌注/谣言工厂/技能系统/神经元点阵图等 |
| 3. 技能管理 | 技能详情/统计/导入/搜索 |
| 4. 玩家默认配置 | 默认专家人数、思考模式 |
| 5. 调度器参数 | 最大轮数、僵持阈值、元讨论间隔 |
| 6. 讨论参数 | 默认讨论模式、目标导向模式 |

设置自动持久化到 `tui_settings.json`，下次启动自动加载。

## 安全与风险声明

> **SLSMDS 是一个实验性系统，涉及多智能体 AI 交互，使用前请知悉以下风险：**

1. **API 费用**：讨论过程中会频繁调用 LLM API，请确保已设置合理的费用上限
2. **输出不可控**：AI 实体可能产生意料之外的输出
3. **数据持久化**：所有讨论记录和检查点保存到本地磁盘
4. **系统稳定性**：技能系统允许执行 Python 代码和 Shell 命令
